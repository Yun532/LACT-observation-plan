# 自定义观测源

页面顶部、单夜工作台和「管理源表」中都有独立的「自定义源」入口。可以手动添加一个目标，或导入本地 CSV／YAML，核对预览后追加到源表。自定义源与 TeVCat、LHAASO 和已选 Fermi 源一起参与年度／月度查询、天空分布、单夜轨迹、天顶角分布及排班，不替换任何已有目录。

## 最少只需坐标

| 字段 | 含义与缺省值 |
| --- | --- |
| `ra` | 必填；赤经，缺省为十进制度数，范围 `[0,360)` |
| `dec` | 必填；赤纬，度数，范围 `[-90,90]` |
| `name` | 选填；源名称，留空按坐标生成 |
| `frame` | 选填；`FK5/J2000`（缺省）或 `ICRS`；也接受 `coordinateFrame` |
| `ra_unit` | 选填；数字赤经使用 `deg`（缺省）或 `hour`；小时范围 `[0,24)` |
| `type` | 选填；源类别，缺省为「未分类」 |
| `notes` | 选填；备注 |

RA 的三个分量用冒号或空格分隔时，始终按**时、分、秒**解析，例如 `08:30:00` 或 `08 30 00` 为 127.5°。`ra_unit` 只指定数字赤经的单位。Dec 支持度数或**度、分、秒**，例如 `-00:30:00` 为 −0.5°。分、秒须小于 60；不接受 `24:00:00`。请按坐标的实际来源选择坐标系，不把银道坐标直接填入 RA／Dec。

以下都是人工示例，不是科学目录数据。最小 CSV：

```csv
ra,dec
120,30
```

带名称与单位的 CSV：

```csv
name,ra,dec,frame,ra_unit,notes
示例 A,120,30,FK5/J2000,deg,十进制度数
示例 B,8.5,-0.5,ICRS,hour,数字赤经采用小时
示例 C,08:30:00,-00:30:00,ICRS,deg,时分秒与度分秒
```

入口内可下载 CSV 模板。含逗号、换行或双引号的文字字段应使用标准 CSV 引号规则。支持 UTF-8 文件及 BOM。

YAML 使用源记录数组，也可以包在 `sources` 字段内：

```yaml
sources:
  - name: 示例 A
    ra: 120
    dec: 30
    frame: FK5/J2000
  - name: 示例 B
    ra: "08:30:00"
    dec: "-00:30:00"
    frame: ICRS
    notes: 临时观测目标
```

只有坐标也可以计算几何观测条件。这个入口暂不导入流强、能谱、延展或自行参数；缺失科学量保持未知，不从坐标推测。LHAASO 二期模型仍使用原有专门的本地 YAML 导入入口。

## 追加、保存与备份

- 单个文件及本机自定义源表导出的 UTF-8 CSV 均不超过 **2 MiB**；单次导入及本机自定义源总数均不超过 **1000 条**。多次追加后也会检查累计导出大小，超限时保留原源表，并提示减少备注或分批管理，确保备份可以重新导入。每条记录最多 32 个字段；导入名称最多 256 字符、类别 128 字符、备注 2048 字符。不支持 YAML 别名、重复字段或不安全的对象键。
- 名称、规范化后的坐标系、RA 和 Dec 共同决定目标标识。四项都相同的记录跳过，已有备注不被覆盖；同名但位置或坐标系不同的记录分别保留，同坐标不同名也分别保留。不与其他科学目录自动合并。
- 添加成功后保存在当前网站、当前浏览器的本地存储中，刷新后恢复；切换公开目录与本地二期目录不移除自定义源。原文件及解析后的坐标不会上传至服务器、GitHub 或 Pages。
- 「导出 CSV」备份整个自定义源表，可在另一个浏览器重新导入。导出文件对可能被电子表格解释为公式的文字增加单引号保护，并使用 `text_encoding=apostrophe-v1` 标记；重新导入时自动还原，请保留该列。
- 浏览器清理数据或更换设备前，应下载 CSV 或计划 JSON。若其他标签页已修改源表，当前页会提示刷新，以免旧内容覆盖新内容。

## 与观测计划一起使用

计划草稿及完整 JSON 在 `customSources` 中保存关注源、叠加轨迹和观测任务实际引用的自定义源定义；不会附带未使用的整张自定义源表。换设备导入计划时，这些定义自动追加到本机自定义源表，已有目标仍保留原有信息。旧计划若只引用公开目录，仍可正常导入。

导入时会检查源标识是否与名称、坐标及坐标系一致，并拒绝缺少定义的自定义目标，不会在旧标识下悄悄替换坐标。下载的计划包含所引用目标的坐标和备注，分享文件时也会分享这些信息。

删除源之前，网站会检查当前任务及本机已保存的公开／私有目录任务。源仍被任务使用时，须先移除对应任务并保存；仅作为关注或叠加目标时可以删除，相关引用会同时清理。删除不会改写已有观测任务的指向。
