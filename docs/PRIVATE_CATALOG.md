# 本地私有目录

网站提供公开的应用代码和公开源表。非公开的二期 LHAASO 目录由持有文件的人在网页中选择，解析、观测窗口计算和绘图均在其浏览器中进行；原文件及解析后的记录不上传至 GitHub、Pages 或远程计算服务。公开部署不内置这些记录、实际统计、示例源名或坐标。

## 使用方式

1. 打开源表管理，选择本机持有的目录文件。导入器检查格式和坐标后，以本地二期目录替换当前一期 LHAASO 条目，保留公开 TeVCat 条目。
2. 页面显示当前目录为非公开本地目录。源表、月度窗口、单夜轨迹、邻近天区和排班都使用该目录的坐标，切换时重新计算。
3. “导入后记住此设备”默认勾选，控制本次选择文件后的保存方式：勾选时将目录的原始文本保存在当前网站来源的 IndexedDB 中，下次打开重新解析；取消勾选时，本次导入的目录仅用于当前页面会话。这个选项只在导入时生效；要移除已经记住的目录，使用“恢复公开源表”或“清除本机私有数据”。浏览器存储不是账号同步，也不是加密保管库。
4. “恢复公开源表”恢复随网站发布的公开目录，并移除浏览器中记住的私有目录。其独立草稿与重点标记仍保留，重新导入内容相同的文件可以继续使用。
5. “清除本机私有数据”在二次确认后清除该网站保存的私有目录、相关草稿和重点标记。它不删除用户电脑上的原始文件或已下载文件，也不清除公开目录的草稿。

只有当前浏览器导入目录后才会看到非公开记录。其他访问者和未导入的设备仍使用公开源表。清除网站数据、换浏览器或换网站来源后，需要重新导入目录。

私有计划草稿与重点标记仍会在其独立空间自动保存，不受目录导入时的记忆选项控制。在共用设备上使用后，可通过“清除本机私有数据”一并移除；如果浏览器拒绝部分存储操作，页面会指出尚未完成的清理。

## 计划与目录版本

私有目录按内容指纹隔离草稿和个人优先级。目录内容变化后，不自动将旧坐标下的任务和重点标记套用到新目录。公开目录继续使用原有草稿空间，切换私有目录不会覆盖它。

导入的计划需要当前目录能识别其中的源，并按当前坐标重新检查。下载的草稿、任务 CSV 和指向文件可能包含非公开名称与坐标；下载仅发生在本机，但文件本身仍属于非公开衍生数据。分享或上传这些文件前应按原目录的使用权限处理。

## 科学信息的使用

目录提供者已确认二期表的 `ra/dec` 使用 **J2000（FK5）坐标，单位为度**。规划采用主空间分量的位置；使用空间模板的记录采用 `ra_dec_ext` 的前两项作为参考位置。附加空间分量与原始参数分别保留，不凭源级 TS 推定某个分量更可靠。坐标分量、能量范围、单位及提供的误差或上限应一并查看。

二期高斯空间模型的 `ext` 为**二维高斯 σ，单位为度**，天空图与邻近图使用其 σ 轮廓。对圆对称二维高斯，半径 σ 内约包含 39.35% 的总量，不能将这条轮廓当作 68% 包容区域、源的硬边界或仪器 PSF。目录的 **95% 位置误差**描述定位不确定性，与源本身展宽独立，不能作为 σ 圈代入。模板的完整形态不会仅凭一个参考位置重建；没有确认定义的其他形态参数保留原值。

不同探测器分量或不同能段的流强不能直接混排。缺失值保持缺失，未探测分量和上限不能当作零值或测得值。关联名称不自动表示同一个物理源，跨目录相近记录不会自动合并。非公开目录的记录不会因导入而变成“已发布”数据。

## 维护与发布边界

- 原始文件放在仓库之外。不要将原始目录、转换后的 JSON、逐源测试快照、真实数据统计或截图加入版本库。
- `public/` 的文件会原样进入构建输出。即使文件已被 `.gitignore` 忽略，也不能把私有文件放在那里；`.gitignore` 不是发布访问控制。
- 仓库仅保留通用导入器和人工构造的测试数据；不把真实私有数据当作自动测试样本。
- 改名、转成 JSON、编码或压缩都不是保密机制。公开静态网站无法保密其下载资源，不能把非公开记录放到 Pages 上再靠界面隐藏。
- 私有科学数据不进入 URL 参数、外部目录查询链接、远程日志或统计服务。应用请求的公开网页资源与私有目录内容相互独立。

仓库的忽略规则覆盖常见的 `2LHAASO` 目录文件名和 `private-data/`，只作为误提交防护；发布前仍需审阅实际提交文件和构建内容。
